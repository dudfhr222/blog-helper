# 블로그 문체 규칙

## 기본 원칙

| 규칙 | 상세 |
|------|------|
| 담백한 톤 | 과장 없이 팩트 중심, 경험 기반 서술 |
| 1인칭 시점 | "~해봤다", "~한 경험이 있다" 형식 |
| 구어체 자제 | "ㅋㅋ", "ㅎㅎ", 인터넷 신조어 금지 |
| 이모지 제한 | 본문 전체에서 최대 2개 |
| 문장 길이 | 한 문장 80자 이내 권장 |
| 문단 길이 | 3~5문장, 모바일 가독성 고려 |

## 금지 표현

### 광고/과장 톤
- `무조건`, `최고의`, `완벽한`, `혁신적`
- `지금 바로`, `혜택`, `무료.*제공`
- `광고`, `협찬`

### 비공식 표현
- `ㅋㅋ`, `ㅎㅎ`, `ㅠㅠ`, `ㅜㅜ`
- `~임`, `~함` (명사형 종결)
- `대박`, `미쳤다`, `실화냐`

## 권장 표현

| 대신 이렇게 | 예시 |
|------------|------|
| 경험 기반 서술 | "직접 써보니 ~한 점이 인상적이었다" |
| 구체적 수치 | "속도가 약 30% 향상되었다" |
| 비교 기반 설명 | "A와 B를 비교하면 ~한 차이가 있다" |
| 독자 행동 유도 | "아래 체크리스트를 따라 해보자" |

## 구조 규칙

| 항목 | 규칙 |
|------|------|
| 서론 | 2~3문장, 왜 이 주제를 다루는지 |
| 본문 | 핵심 내용을 섹션별로 구분 |
| 결론 | 1가지 행동 유도 (CTA) |
| 소제목 | 질문형 또는 핵심 키워드 포함 |
| 리스트 | 3~7개 항목, 불릿 또는 번호 |
