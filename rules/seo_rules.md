# SEO 최적화 규칙

## 제목 규칙

| 규칙 | 설명 |
|------|------|
| 핵심 키워드 포함 | primary keyword가 제목에 반드시 포함 |
| 40자 이내 | 검색 결과에서 잘리지 않도록 |
| 호기심 유발 | "~란?", "~비교", "~정리", "~하는 법" 패턴 |
| 숫자 활용 | "3가지", "5단계" 등 구체적 숫자 |
| 제목 후보 3개 | SEO 관점에서 3가지 변형 제안 |

## 키워드 배치

| 위치 | 규칙 |
|------|------|
| 본문 상단 200자 | primary keyword 반드시 등장 |
| 소제목 | 2개 이상의 소제목에 키워드 포함 |
| 본문 전체 | 키워드 밀도 1~3% (자연스럽게) |
| 마무리 | primary keyword 재언급 |

## 태그 규칙

| 규칙 | 설명 |
|------|------|
| 최대 10개 | 네이버 블로그 태그 제한 |
| primary keywords | 반드시 포함 |
| secondary keywords | 가능한 포함 |
| 범용 태그 | 카테고리별 고정 태그 추가 |
| 중복 제거 | 동일 의미 태그 통합 |

### 카테고리별 범용 태그

개발/AI는 topic/keywords에서 서브 카테고리를 감지해 태그셋을 선택한다.

| 카테고리 | 서브 카테고리 감지 기준 | 범용 태그 |
|----------|------------------------|-----------|
| 개발/AI — 알고리즘 | keywords 또는 topic에 BFS, DFS, DP, 동적프로그래밍, 그리디, 다익스트라, 플로이드, MST, 백트래킹, 시뮬레이션, 투포인터, 자료구조 등 포함 | `알고리즘`, `코딩테스트`, `자료구조`, `파이썬`, `백준` |
| 개발/AI — AI/자동화 | keywords 또는 topic에 에이전트, 자동화, Claude, LLM, AI, GPT, 워크플로우, 블로그자동화 등 포함 | `AI`, `자동화`, `에이전트`, `블로그운영`, `워크플로우` |
| 개발/AI — 기본 | 위 두 조건 모두 미해당 | `개발`, `프로그래밍`, `개발자`, `코딩` |
| 맛집 | — | `맛집추천`, `맛집리뷰`, `먹스타그램` |
| 여행 | — | `여행추천`, `여행코스`, `국내여행` |

감지는 대소문자 무시, 부분 일치로 판단한다. 두 조건이 동시에 해당하면 알고리즘 태그셋을 우선한다.

## 메타 설명 (Summary)

| 규칙 | 설명 |
|------|------|
