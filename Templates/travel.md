# 여행 카테고리 템플릿

## 글 구조

**흐름**: 동선 → 팁 → 비용 → 추천 루트

### 아웃라인

```
1) 추천 동선 (시간순)
   - 시간대별 방문 장소 나열
   - 이동 시간 포함
   - 지도 링크 또는 위치 설명
   ★ [IMG 권장 위치 1] 섹션 1 끝에 {{IMG:slug}} — 가장 인상적인 대표 장소 사진
   ★ [IMG 권장 위치 2] 동선 중간에 {{IMG:slug}} — 두 번째 주요 스팟 사진

2) 현지 팁 (교통/예약/꿀팁)
   - 교통: 대중교통 vs 차량, 주차 정보
   - 예약: 필수 예약 여부, 예약 방법
   - 꿀팁: 현지인만 아는 정보, 시간 절약법

3) 비용 정리 (항목별)
   - 교통비, 입장료, 식비, 숙박비 항목별
   - 총 예산 요약
   - 절약 팁 (할인, 패스, 무료 스팟)

4) 추천 루트: 반일 코스 vs 종일 코스
   - 반일 코스 (3~4시간)
   - 종일 코스 (6~8시간)
   - 각 코스별 핵심 포인트
   ★ [IMG 권장 위치 3] 섹션 4 끝에 {{IMG:slug}} — 전망 또는 여행 하이라이트 사진
   ★ [IMG 권장 위치 4, 선택] 마지막에 {{IMG:slug}} — 분위기 컷 (석양, 야경 등)
```

## 적용 의도

- 여행 글은 **동선(루트)이 핵심** — 시간 순서대로 따라갈 수 있어야 함
- 현지 팁으로 가치 추가
- 비용 정보로 예산 계획 지원
- 추천 루트(반일/종일)로 행동 유도

## 톤 가이드

| 항목 | 가이드 |
|------|--------|
| 어조 | 여행 다녀온 사람이 친구에게 알려주는 느낌 |
| 사진 | 장소별 사진 (있으면) |
| 정보 정확성 | 영업시간, 가격 등 최신 정보 확인 |
| 길이 | 2000~3000자 |
