# 개발/AI 카테고리 템플릿

## 글 구조

**흐름**: 문제 → 해결 → 함정 → 체크리스트

### 아웃라인

```
1) 이런 상황에서 막힌다 (문제 정의)
   - 독자가 공감할 수 있는 실무 상황 제시
   - "~하려고 했는데 ~에서 막혔다" 패턴

2) 핵심 해결 구조 (개념 + 코드)
   - 해결 과정을 단계별로 설명
   - 코드 스니펫 또는 다이어그램 포함
   - "왜 이렇게 하는지" 근거 설명
   ★ [IMG 권장 위치 1] 섹션 2 끝에 {{IMG:slug}} — 전체 흐름 다이어그램 또는 코드 실행 결과 스크린샷

3) 초심자 함정 3가지
   - 자주 빠지는 실수/오해 경고
   - 각 함정별 해결법 제시
   - 실제 에러 메시지 예시 (있으면)
   ★ [IMG 권장 위치 2] 섹션 3 끝에 {{IMG:slug}} — 에러 화면 또는 잘못된 vs 올바른 비교 스크린샷

4) 체크리스트 (바로 적용 가능)
   - keywords에서 추출한 핵심 항목
   - 즉시 실행 가능한 행동 목록
   - "오늘 바로 할 수 있는 1가지"로 마무리
   ★ [IMG 권장 위치 3, 선택] 체크리스트 앞에 {{IMG:slug}} — 최종 결과물 스크린샷
```

## 적용 의도

- 개발자/실무자 독자는 **문제 상황에서 출발**해야 공감
- 해결 과정을 보여준 뒤, 자주 빠지는 함정을 경고
- 마지막에 체크리스트로 행동 유도

## 톤 가이드

| 항목 | 가이드 |
|------|--------|
| 어조 | 경험자가 후배에게 설명하는 느낌 |
| 기술 용어 | 영어 유지, 첫 등장 시 간단 설명 |
| 코드 | 최소한의 동작 코드, 주석 포함 |
| 길이 | 2000~3000자 (코드 제외) |

## 제목 패턴

- `[기술명]란? [핵심 키워드] 정리`
- `[기술A] vs [기술B] 비교: [관점]`
- `[기술명] 실전 적용: [목표] 하는 법`
- `[기술명] 초심자가 빠지는 3가지 함정`
