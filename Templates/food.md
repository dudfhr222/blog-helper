# 맛집 카테고리 템플릿

## 글 구조

**흐름**: 결론 → 근거 → 추천 조합 → 주의사항

### 아웃라인

```
1) 한줄 결론: 여기 갈 만한가?
   - 추천 여부를 먼저 명확히 제시
   - 별점 또는 한 줄 평가
   - "~한 사람에게 추천"
   ★ [IMG 권장 위치 1] 섹션 1 끝에 {{IMG:slug}} — 가장 자신 있는 대표 메뉴 사진

2) 근거: 맛 / 분위기 / 가성비
   - 맛: 대표 메뉴 2~3개 평가
   - 분위기: 인테리어, 좌석, 소음 수준
   - 가성비: 가격대, 양, 만족도
   ★ [IMG 권장 위치 2] 섹션 2 끝에 {{IMG:slug}} — 매장 분위기 또는 인테리어 사진

3) 추천 조합: 이렇게 주문하세요
   - 메뉴 세트 추천 (2인/4인 기준)
   - 사이드/음료 페어링
   - "이건 패스" 메뉴도 솔직히
   ★ [IMG 권장 위치 3] 섹션 3 끝에 {{IMG:slug}} — 추천 조합 메뉴 전체 테이블 샷

4) 주의사항: 웨이팅·주차·브레이크타임
   - 웨이팅 예상 시간, 예약 가능 여부
   - 주차 정보 (유/무료, 주변 대안)
   - 브레이크타임, 라스트오더
   - 방문 팁 (피크 시간 피하기 등)
   ★ [IMG 권장 위치 4, 선택] 섹션 4 끝에 {{IMG:slug}} — 외관 또는 간판 사진
```

## 적용 의도

- 맛집 글은 **결론(추천 여부)을 먼저** 제시해야 이탈률 낮음
- 근거(맛, 분위기, 가성비)로 뒷받침
- 추천 조합으로 실용 정보 제공
- 주의사항으로 마무리

## 톤 가이드

| 항목 | 가이드 |
|------|--------|
| 어조 | 친구에게 솔직하게 추천하는 느낌 |
| 사진 | 음식 사진 필수 (있으면) |
| 가격 | 구체적 가격 명시 |
| 길이 | 1800~2500자 |

## 제목 패턴

- `[지역] [가게명] 솔직 후기: [핵심 메뉴] 먹어봤다`
- `[가게명] 추천 메뉴 BEST 3 + 주문 팁`
- `[지역] 맛집 [가게명]: 웨이팅 없이 가는 법`
