# 코딩테스트 입문 복습 정리

오늘 풀었던 문제를 기준으로, 블로그에 정리하기 좋게 문제 유형, 핵심 아이디어, 사용한 자료구조, 반복문 구조, 다음에 떠올릴 말을 정리한다.

---

## 1. 다항식 더하기

### 문제 유형
문자열 파싱 / 조건 분기 / 누적 합산

### 핵심 아이디어
다항식을 공백 기준으로 나눈 뒤, 각 항이 x항인지 상수항인지 구분한다.

예시:

```python
"3x + 7 + x".split()\blog-helper
# ['3x', '+', '7', '+', 'x']
```

- `x`가 포함된 항은 계수만 뽑아서 `x_cnt`에 더한다.
- 숫자만 있는 항은 `int_val`에 더한다.
- `+`는 계산에 필요 없으므로 건너뛴다.

### 쓴 자료구조
별도 자료구조보다는 누적 변수 2개를 사용한다.

```python
x_cnt = 0     # x 계수 합
int_val = 0   # 상수항 합
```

### 반복문 구조

```python
for i in polynomial.split():
    if i == "+":
        continue

    if "x" in i:
        # x항 처리
    else:
        # 상수항 처리
```

### 주의할 점
`"12x"`처럼 계수가 두 자리 이상일 수 있으므로 `i[0]`만 보면 안 된다.

```python
coef = i.replace("x", "")
```

- `"x"`는 계수 1이다.
- `"3x"`는 계수 3이다.
- `"12x"`는 계수 12이다.

### 다음에 비슷한 문제 나오면 떠올릴 말
문자열 식 문제는 먼저 쪼갠다. 그 다음 항을 분류하고, 각각 누적한 뒤, 마지막에 출력 형식을 맞춘다.

## 2. 안전지대

### 문제 유형
2차원 배열 / 좌표 이동 / 주변 칸 표시

### 핵심 아이디어
지뢰가 있는 칸을 찾고, 그 칸 주변 8칸과 자기 자신을 위험지역으로 표시한다.

원본 `board`를 직접 바꾸기보다, 위험지역 표시용 배열 `danger`를 따로 만든다.

### 쓴 자료구조
`n x n` 크기의 2차원 배열을 사용한다.

```python
danger = []

for i in range(n):
    danger.append([0] * n)
```

- `danger[r][c] = 1`이면 위험지역이다.
- `danger[r][c] = 0`이면 아직 안전지역 후보이다.

### 반복문 구조

```python
for row_idx in range(n):
    for col_idx in range(n):
        if board[row_idx][col_idx] == 1:
            for dr in [-1, 0, 1]:
                for dc in [-1, 0, 1]:
                    nr = row_idx + dr
                    nc = col_idx + dc
```

마지막에는 `danger` 배열에서 0인 칸을 센다.

```python
answer = 0

for row_idx in range(n):
    for col_idx in range(n):
        if danger[row_idx][col_idx] == 0:
            answer += 1
```

### 주의할 점
주변 좌표가 배열 범위를 벗어날 수 있으므로 반드시 범위 체크를 해야 한다.

```python
if 0 <= nr < n and 0 <= nc < n:
    danger[nr][nc] = 1
```

### 다음에 비슷한 문제 나오면 떠올릴 말
격자 문제에서 주변 칸을 봐야 하면 `현재 좌표 + 방향 변화량`을 사용한다.

```python
nr = r + dr
nc = c + dc
```

좌표 문제에서는 항상 범위 체크가 필요하다.

## 3. 평행

### 문제 유형
좌표 / 기울기 비교 / 경우의 수

### 핵심 아이디어
점 4개를 두 점씩 이어서 선분 2개를 만든다.
두 직선이 평행인지 확인하려면 기울기를 비교한다.

점 4개를 두 선분으로 나누는 경우는 3개뿐이다.

```text
0-1 / 2-3
0-2 / 1-3
0-3 / 1-2
```

기울기는 원래 다음처럼 구한다.

```text
기울기 = y 변화량 / x 변화량
```

하지만 나눗셈으로 비교하면 소수 오차가 생길 수 있으므로 곱셈으로 비교한다.

```python
(y2 - y1) * (x4 - x3) == (y4 - y3) * (x2 - x1)
```

### 쓴 자료구조
추가 자료구조는 거의 사용하지 않는다.
좌표 배열 `dots`에서 값을 꺼내 비교한다.

```python
x1, y1 = dots[0]
x2, y2 = dots[1]
```

### 반복문 구조
반복문 없이 3가지 경우를 직접 비교해도 충분하다.

```python
if is_parallel(0, 1, 2, 3):
    return 1

if is_parallel(0, 2, 1, 3):
    return 1

if is_parallel(0, 3, 1, 2):
    return 1

return 0
```

### 다음에 비슷한 문제 나오면 떠올릴 말
점 4개로 두 선분을 만드는 문제는 경우의 수가 3개뿐이다.
기울기는 직접 나누지 말고, 분모를 없애서 곱셈으로 비교한다.

## 4. 겹치는 선분의 길이

### 문제 유형
구간 표시 / 카운팅 배열 / 중복 제거

### 핵심 아이디어
선분끼리 직접 비교하면 중복 계산이 생길 수 있다.
대신 좌표 칸마다 몇 개의 선분이 덮고 있는지 센다.

예를 들어 `[2, 5]`는 다음 구간을 덮는다.

```text
2~3
3~4
4~5
```

코드에서는 다음처럼 표현한다.

```python
for i in range(2, 5):
```

즉, `2`, `3`, `4`를 표시하면 길이 3을 표현할 수 있다.

### 쓴 자료구조
좌표별 덮인 횟수를 저장하는 배열을 사용한다.

```python
count = [0] * 201
```

좌표 범위가 `-100 ~ 100`이기 때문에 인덱스로 사용하려면 `+100`을 해준다.

```python
count[i + 100] += 1
```

변환 예시:

```text
좌표 -100 -> 인덱스 0
좌표 0    -> 인덱스 100
좌표 100  -> 인덱스 200
```

### 반복문 구조

```python
for start, end in lines:
    for i in range(start, end):
        count[i + 100] += 1
```

그 다음 2번 이상 덮인 칸만 센다.

```python
answer = 0

for c in count:
    if c >= 2:
        answer += 1
```

### 다음에 비슷한 문제 나오면 떠올릴 말
좌표 범위가 작으면 선분끼리 복잡하게 비교하지 말고 전체 칸을 직접 칠해도 된다.

겹친 길이는 선분 쌍의 겹침을 더하는 것이 아니라, 2번 이상 칠해진 위치의 개수를 세는 것이다.

# 오늘 얻은 코테 감각

## 1. 바로 코드 치지 말고 먼저 분류하기
문제를 보면 먼저 아래를 판단한다.

```text
문자열인가?
2차원 배열인가?
좌표인가?
구간인가?
개수 세기인가?
모든 경우 확인인가?
```

## 2. 자료구조를 먼저 정하기
오늘 문제들은 자료구조를 먼저 잡으면 훨씬 쉬워졌다.

```text
다항식 더하기 -> x_cnt, int_val
안전지대 -> danger 2차원 배열
평행 -> 추가 자료구조 없음, 좌표 직접 비교
겹치는 선분 -> count 배열
```

## 3. 범위가 작으면 직접 세기
코딩테스트 입문 문제는 제한사항이 힌트인 경우가 많다.

```text
좌표 -100 ~ 100
길이 < 100
n <= 100
```

이런 조건이면 복잡한 수학보다 전체를 돌면서 표시하는 방식이 더 쉬울 때가 많다.

## 4. 좌표 문제는 현재 위치 + 변화량
격자 주변 탐색은 거의 이 패턴이다.

```python
for dr in [-1, 0, 1]:
    for dc in [-1, 0, 1]:
        nr = r + dr
        nc = c + dc
```

## 5. 구간 문제는 start부터 end 전까지
선분 `[a, b]`의 길이는 보통 다음처럼 생각한다.

```python
for i in range(a, b):
```

예를 들어 `[2, 5]`는 `2`, `3`, `4` 총 3칸이다.
